# A.I. text and drawing recognition

### Using A.I. recognition (OpenAI or Gemini)

In MysterSmith you can use A.I. based text and drawing recognition, which is using either GPT by OpenAI, or Gemini by Google. To use these A.I. based recognition engines,  **you don't need to buy any text recognition credits from me**, but you'll have to create your own OpenAI or Gemini API key. I recommend using Gemini, as most of their models are FREE to use (except the Pro models).

---

 

### Obtaining your OpenAI API key

To be able to use GPT-based A.I. text recognition (also drawing recognition and analysis), you will need to get an OpenaAI API key, and top up your balance (performing one routine will cost you only around 0.01-0.02 USD). 
 
Follow these steps to get your OpenAI API key, to use in the MysterSmith app:

* create an OpenAI account: 
 <https://platform.openai.com/signup>
* go to your billing overview: 
 <https://platform.openai.com/account/billing/overview>
* add your payment details
* top up your API balance (with at least 10 USD)
* create an API key: 
 <https://platform.openai.com/api-keys> 
 
**IMPORTANT:** copy your API key as soon as you create it, you won't be able to view/copy it later!!!

* make sure you have a username and PIN set up in in MysterSmith (Account Settings - Show details)
* in MysterSmith go to Settings, and scroll down to the **A.I. FEATURES** section
* paste your API key to "OpenAI API key"
* select your language at "A.I. language"
* in TEXT RECOGNITION settings select any GPT (OpenAI) model as the recognition engine
* set "Automatic text recognition" to 3 sec, and enable "Show recognized text"
* go to the Perform page and start the Doodle screen
* write anything on the screen (or use an impression board)
* the recognized text will pop up at the bottom of the screen
* you can also try automatically performing an action after text recognition (see the screenshots and photos below)
 

---

### How to create your Gemini API key

You can also use A.I. text and drawing recognition provided by Google Gemini, which can be used FREE of charge (up to a specified limit, except the Pro models). 
 
Here are the steps to create your Gemini API key, and to use it in MysterSmith:

* visit the Google A.I. Studio: 
 <https://aistudio.google.com/apikey>
* accept the Terms of Service
* select API keys - "Create API key"
* choose an existing project, or select "Create API key in new project"

**IMPORTANT:** copy your API key as soon as you create it, you won't be able to view/copy it later!!!

* make sure you have a username and PIN set up in in MysterSmith (Account Settings - Show details)
* in MysterSmith go to Settings, and scroll down to the **A.I. FEATURES** section
* enter your Gemini API key
* in TEXT RECOGNITION settings select any Gemini model (3.1 Flash Lite recommended)
* set "Automatic text recognition" to 3 sec, and enable "Show recognized text"
* go to the Perform page and start the Doodle screen
* write anything on the screen (or use an impression board)
* the recognized text will pop up at the bottom of the screen
* you can also try automatically performing an action after text recognition (see the screenshots and photos below)
