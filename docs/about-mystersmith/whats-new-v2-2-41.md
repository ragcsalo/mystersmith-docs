# What's new in MysterSmith v2.2.41

!!! info "Looking for the latest?"
    This is the archived **v2.2.41** release page. For the newest features, see [**What's new in v2.3.11**](whats-new.md).

A big update just landed, packed with new input methods, smarter recognition, deeper device support and a redesigned Settings page. Here are the highlights. :-)

!!! note "Testing the new build?"
    If you're helping test **v2.2.41**, here's a full step-by-step [**testing guide**](testing-new-features-v2-2-41.md) — a checklist covering every new feature below.

---

## Smarter handwriting recognition

MysterSmith now understands *how* you write, not just *what* you write.

!!! tip "New: Automatic page orientation"
    Turn on **Text recognition → Page orientation → automatic** and you can write at **any angle** — tilted, diagonal, even upside down. The app reads the pen strokes, works out the rotation, and straightens the image *before* it's recognized (and before it's saved to the Image Buffer). No more turning the pad to line things up.

* automatic orientation detection for handwriting recognition
* **combined display** of the original handwriting **and** the recognized text — on the BLACK screen and on the Lumen Prism
* recognized text on the BLACK screen is now **auto-fitted** (wrapped and sized to fill the frame)
* new **A.I. text-to-voice** feature using ElevenLabs (bring your own API key)

---

## New input methods

* **Dice Input** — supporting Spotted Dice, KMD (by Marc-Antoine), Pitata Dice, BLE Dice and GoDice
* configurable **dice display** for e-ink boards, keychains, printers, the Doodle screen and more
* **Short card names** option for the SWIPE input method (2H, KC, 10D, AS…)
* option to save the **full playing card name** when sending a card

---

## Actions & automation

* the new **ACTION LIST** feature — perform a whole chain of actions from a single trigger
* new action: **Switch between drawing/text** — jump between the original handwriting and its recognized text
* optional **action after sending a color**
* **connected devices can be saved for a routine**, and reconnected even from the background

---

## Displays & devices

* add **any custom background** when sending text to Teleport, Prism or E-ink tags
* use the **last photo from your gallery** as a custom background
* new customization options for **Teleport, Prism and E-ink tags**
* new customization options for the **Lumen Duo, Lumen Eye, Iarvel Card and MrCard**
* a **"display details" test image** for Teleport, Prism and E-ink tags
* an **"action after transfer finished"** option for Teleport, Prism and the Reinkstone NFC cases
* added support for **Lumen Spectra**
* added support for the **Nova Sharpie** camera pen (by Umesh)
* added support for the **Motherboard-X API**

---

## Settings & personalization

* **redesigned Settings page** with a built-in **search bar**
* new **Guided Tours** (in the User Guide) — step-by-step walkthroughs of key setups, with many more to come… soon
* mark features and devices as **favorites**, and hide everything you don't own or don't use
* **custom settings are now saved per device** (printers and display devices)
* **save your devices cross-platform** — set them up once, use them on Android and iOS
* new option: **Auto-switch Wi-Fi / cellular** (in OTHER SETTINGS)

---

## Buffers

* fixed showing the **last / previous / next text** from the Text Buffer
* fixed showing the **last / previous / next image** from the Image Buffer

---

## Fixes & housekeeping

* fixed a connection bug with the Labco Scrabble
* fixed the text recognition method selector when no A.I. engine is selected

---

!!! warning "Add-on requirements from 1 October 2026"
    To keep things sustainable, two add-ons become required for certain devices from **1 October 2026**:

    * **External Displays** — for all PeekSmith models, Bond, MrCard, Teleport, Quantum, SB Watch 2
    * **Advanced Input Methods** — for Atom 2, all PeekSmith models, Bond, MrCard, Quantum, SB Watch 2, Ray, GhostMove

    Everything else that's currently free stays free.
