## On iOS

You can install the MysterSmith app from TestFlight:

[![](https://mystersmith.info/assets/images/TestFlight.png){ height=100 }](https://testflight.apple.com/join/96mRQPZ4)

If you see the "<i>The developer removed you from the test program</i>" message, don't panic, just follow these steps:

- scroll down, and select "Stop Testing"
- open this download page on the info website
- install the update by clicking the TestFlight button
- start the app, and install any other minor updates
