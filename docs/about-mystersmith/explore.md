
# What can I do with MysterSmith?

The MysterSmith app has 3 main features: 
 

* **Receive information** 
* **Transform data / generate new content** 
* **Send information** 

 

---

 

## Receiving information

MysterSmith can receive information from different sources: 
 
 **Bluetooth devices:** 

* impression boards / camera pens
* NFC readers
* BT remotes
* PeekSmith 3 (buttons, motion, magnet detector)
* other devices (like Labco Scrabble)

 
 **Other apps:** 

* data sent via the custom URL scheme (mystersmith://?text=xxxx)
* data received from WEB APIs (WEB-polling from any source)
* local HTTP requests (http://localhost:62369/data?text=xxxxx)

 
 **Other WEB sources:** 

* text from any WEB browser (WEB-input)
* drawings, handwritings using the WEB-doodle

 
 **Manual input in the app (*by an assistant*):** 

* impromptu text (or predefined texts)
* playing cards
* colors
* drawings

 
The **Advanced Input Methods add-on** offers inputs like: 

* fake passcode screen
* swipe screen (for numbers)
* more Bluetooth remotes
* voice recognition
* Bluetooth dice (Spotted Dice, KMD, Pitata Dice, GoDice)
* fake calculator input
* phone motion control

The received data (text or image) is **stored in the text/image buffer** in the app, and also in the cloud (for API access). 
 

---

 

## Transforming data, generating new content

You can work with any text or image that is stored in the text/image buffer. At the moment the app offers these options: 
 

* **recognize**  handwritten text/numbers, celebrity names, timestamps, ESP signs, playing cards
* **correct** misspellings and typos in recognized handwrittemn texts
* **analyze** drawings and turn them into keywords or longer descriptions
* create an acronym/acrostic from the letters of a word
* turn numbers to an ESP symbol or a smiley, or generate a magic square
* turn any 3-4 digit number into **Pi Revelations** numbers
* display the **dictionary location** of any English word (using the Dictionary API add-on)
* re-order recognized numbers into a list of **LOTTO numbers** 
* using the **custom A.I. prompt**, you can turn any recognized text/drawing into anything
* **create sharpie drawings** from text, drawings or images (received from other apps)
* "outsource" the tranformation process to other apps, like **Bridge** (send data, and receive the result)

## Sending information

Finally, when you have a text or image prepared, you can send it to various devices and 3rd party apps. 
 
 **You can peek** text, images and drawings on: 

* PeekSmith 3 device
* Electricks Bond watch
* Super Sharpie
* Sharpeek marker
* MrCard
* Iarvel credit card
* Lumen Prism
* Lumen Prism PRO
* Lumen Spectra
* Lumen Duo
* Lumen Eye
* Apple watch
* WearOS watch
* any smartwatch (using notifications)
* the WEB-screen (in any WEB-browser)

 **You can hear** recognized text or the description of a recognized drawing, photo through a secret earpiece. You can even generate A.I. speech and play it through bone conductor devices.
 
 **You can display** predicted text (printed or handwritten), drawings, photos, magic squares, clock predictions etc. on e-ink devices, like:

* Teleport
* Pitata Inversion Board
* Pitata Inversion Board Ultra
* Pitata Prediction Keychain
* Pitata Infinite Tag
* Iarvel Peekboard
* Iarvel Keychain
* Iarvel Key Prediction PRO
* Spirit Echo
* Real Board by Yao
* The Missing Tape (VHS) by Yao
* The Motherboard
* The Omega Board
* Reinkstone iPhone cases
* a bunch of e-ink tags

 **You can print** predictions of text, drawings, photos, magic squares, clock predictions etc. on printers, like:

* Glyphs / Peripage
* Cosmos / L2
* Pitata Printer
* Paperang printers
* Cat printers

 
...with support coming soon for COLOR printers, like: 

* Pitata Photo Prediction
* HP Sprocket (1st edition)
* HP Sprocket Plus
* Polaroid ZIP
* Polaroid Mint

 **You can send** text and images to:

* any 3rd party app, using custom URL schemes
* any WEB API
