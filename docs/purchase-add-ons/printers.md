# Printers (add-on)

The Printers add-on is a premium feature for the MysterSmith app. The price of the add-on is currently **45 EUR** (one time fee), but of course it's also **included in both subscription plans** (BASIC and PREMIUM).  
  
With the Printers add-on activated, you can connect your **Cosmos/L2 printer**, **Glyphs/Peripage printer**, **Pitata Printer** or **Cat printer**in MysterSmith. You can print handwritten text, signatures, playing cards, doodle drawings, clock predictions and magic squares.  
  
  

---

  

### Purchasing the Printers add-on

If you don't want to subscribe for MysterSmith (to get all the available add-ons), you can also purchase the Printers add-on for **45 EUR** by clicking here:

**[bsmagic.app/payment/?item=printers](https://bsmagic.app/payment/?item=printers)**

### Activating your code

If you are a MysterSmith subscriber, the add-on is already activated for you.  
  
If you have purchased the add-on separately, or received the code as a gift, you can activate the code by entering the code in MysterSmith, in the **ACCOUNT STTINGS** section. Just look for the line "**Do you have a code?**", and "**Tap to enter**", and the code activation screen will pop up.  
  
After the code is activated, you can check all your activated add-ons on your account details page. Just tap "**Show details**" under ACCOUNT SETTINGS, and scroll down to the **PURCHASED ADD-ONS** section. If you have an active MysterSmith subscription, you will have access to all the available add-ons.
