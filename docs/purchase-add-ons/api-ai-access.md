# API + A.I. access (add-on)

The API + A.I. access add-on is a premium feature for the MysterSmith and PeekSmith apps (you can use it in both apps). The price of the add-on is currently **45 EUR** (one time fee), but of course it's also **included in both subscription plans** (BASIC and PREMIUM).  
  
With the API + A.I. access add-on activated, you'll be able to **send data from the MysterSmith app to any 3rd party WEB API**, so you can integrate with other magic apps easily. You will also be able to use **A.I. based features** in the app, using your own **OpenAI API key** (see below).  
  

---

  

### Purchasing the API + A.I. access add-on separately

If you don't want to subscribe for MysterSmith (to get all the available add-ons), you can also purchase the API + A.I. access add-on separately for **45 EUR** by clicking here:

**[bsmagic.app/payment/?item=sendtoapi](https://bsmagic.app/payment/?item=sendtoapi)**

### Activating your code

If you are a MysterSmith subscriber, the add-on is already activated for you.  
  
If you have purchased the add-on separately, or received the code as a gift, you can activate the code by entering the code in MysterSmith, in the **ACCOUNT STTINGS** section. Just look for the line "**Do you have a code?**", and "**Tap to enter**", and the code activation screen will pop up.  
  
After the code is activated, you can check all your activated add-ons on your account details page. Just tap "**Show details**" under ACCOUNT SETTINGS, and scroll down to the **PURCHASED ADD-ONS** section. If you have an active MysterSmith subscription, you will have access to all the available add-ons.

### Using A.I. functions (text recognition, etc.)

If you already have the API + A.I. access add-on, you can enter **your own OpenAI API key** to be able to use A.I. based features, like text recognition, image analysis and more. To use this A.I. based recognition **you don't need to buy any text recognition credits from me**, you will pay directly to OpenAI.  
  
  
[**Click here to read the guide about obtaining the OpenAI API key**](https://mystersmith.info/site/user-guide/ai-recognition/)
