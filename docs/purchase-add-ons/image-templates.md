# Image Template Editor (add-on)

The Image Template Editor add-on is a premium feature for the MysterSmith app. The price of the add-on is currently  **70 EUR**  (one time fee), but of course it's also  **included in all subscription plans**  (MINI, BASIC and PREMIUM).

With the Image Template Editor you can **design a picture once, and fill it in during the show**: a background image, any number of images and text fields — the spectator's word, a fresh A.I. drawing, a calculated number. The finished image can be shown on any supported display device or printed.

* **Unlimited templates:** a background image, and an unlimited number of image and text placeholders.
* **Text fields:** Text Buffer variables (`#TEXT`, `#TXT1`..`#TXT9`, `#LAST1`..`#LAST9`), with formatting.
* **Image fields:** the images of the [Image Buffer](../user-guide/image-buffer.md) (`#IMAGE`, `#IMG1`..`#IMG9`, `#LAST1`..`#LAST9`).
* **Send it anywhere:** printers, the Doodle screen, Lumen Prism, Teleport, Inversion Board / Ultra, Iarvel Peek Board, RealBoard, E-ink tags, The Missing Tape, color photo printers — it is fitted to the device automatically.
* **Saved with your routines and your account**, and you can **share** a template with another magician with a code.

All the details: **[Image templates](../user-guide/image-templates.md)** in the User Guide.

### Activating your code

If you are a MysterSmith subscriber, the add-on is already activated for you.

If you have purchased the add-on separately, or received the code as a gift, you can activate the code by entering it in MysterSmith, in the  **ACCOUNT SETTINGS**  section. Just look for the line " **Do you have a code?** ", and " **Tap to enter** ", and the code activation screen will pop up.

After the code is activated, you can check all your activated add-ons on your account details page. Just tap " **Show details** " under ACCOUNT SETTINGS, and scroll down to the  **ACTIVATED FEATURES**  section.
