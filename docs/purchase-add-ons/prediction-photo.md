# Prediction Photo (add-on)

The Prediction Photo add-on is a premium feature for the MysterSmith app. The price of the add-on is currently  **60 EUR**  (one time fee), but of course it's also  **included in all subscription plans**  (MINI, BASIC and PREMIUM).

With the Prediction Photo add-on you can **save a picture to the gallery of your phone or tablet as if it had been taken earlier** — a prediction that was "photographed" hours or days before the spectator made the choice. More features will be added soon.

* **Any image:** the current image of the [Image Buffer](../user-guide/image-buffer.md) — an A.I. drawing, a doodle, an image template, a picture from WEB-polling...
* **Photo date:** *now*, *days ago*, or a *custom date & time*.
* **Time source:** a *fixed time*, or the **last time from the Text Buffer** (a time the spectator named).
* **Overwrite last photo** (Android): a new prediction photo replaces the one saved before, so only one stays in the gallery.
* **Actions:** *save image to phone gallery* and *delete last saved photo* — on a remote button, a volume button or in an action list.
* On Android the photo gets the right date in every gallery app.

The settings are under **Settings → Output / Screens → PREDICTION PHOTO**.

### Activating your code

If you are a MysterSmith subscriber, the add-on is already activated for you.

If you have purchased the add-on separately, or received the code as a gift, you can activate the code by entering it in MysterSmith, in the  **ACCOUNT SETTINGS**  section. Just look for the line " **Do you have a code?** ", and " **Tap to enter** ", and the code activation screen will pop up.

After the code is activated, you can check all your activated add-ons on your account details page. Just tap " **Show details** " under ACCOUNT SETTINGS, and scroll down to the  **ACTIVATED FEATURES**  section.
