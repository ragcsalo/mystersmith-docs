# Advanced Input Methods

The Advanced Input Methods add-on is a premium feature for the MysterSmith app. The price of the add-on is currently **45 EUR** (one time fee), but of course it's also **included in both subscription plans** (BASIC and PREMIUM).   
  
With this add-on you can enable some advanced input methods.  
  
**Currently available input methods:**  

* swipe input
* fake passcode input
* remote control input (Atom 2, Pitata Palm Remote, Wilson Nexus, Unifi Thumper V2)

  
**Other input methods will be added** gradually during the coming weeks/months:  

* voice recognition
* bluetooth dice input
* and probably some other methods...

### Purchasing the Advanced Input Methods add-on

If you don't want to subscribe for MysterSmith (to get all the available add-ons), you can also purchase the Advanced Input Methods add-on for **45 EUR** by clicking here:

**[bsmagic.app/payment/?item=input](https://bsmagic.app/payment/?item=input)**

### Activating your code

If you are a MysterSmith subscriber, the add-on is already activated for you.  
  
If you have purchased the add-on separately, or received the code as a gift, you can activate the code by entering the code in MysterSmith, in the **ACCOUNT STTINGS** section. Just look for the line "**Do you have a code?**", and "**Tap to enter**", and the code activation screen will pop up.  
  
After the code is activated, you can check all your activated add-ons on your account details page. Just tap "**Show details**" under ACCOUNT SETTINGS, and scroll down to the **PURCHASED ADD-ONS** section. If you have an active MysterSmith subscription, you will have access to all the available add-ons.
