# F.A.Q. - read before you ask

**- What can I do with MysterSmith?**

- You can receive data (from devices or other apps), you can process/transform that information or generate new data, and finally you can send the result to various devices or any other app. **[Click here to explore the possibilities...](https://mystersmith.info/site/about-mystersmith/explore/)**

---

**- Does the basic app have FREE features?**

- Good news: many features in MysterSmith are FREE for everyone!!! :-) You can receive data from many sources, display the data on some screens/devices, and you also get some free text recognition credits. **[Click here to discover all the FREE features...](https://mystersmith.info/site/about-mystersmith/free-features/)**

---

**- Is MysterSmith a subscription-only app? Do I need to subscribe to use it?**

- No, no, ABSOLUTELY NOT!!! You can install and use MysterSmith as if it were the PeekSmith app. You can use every feature, every add-on that you already used in the PeekSmith app (except for some features added in the PeekSmith app after March 2025) - and you will get lots of new FREE features and functions as well!!! There are new add-ons that you can buy separately if you need them, or you CAN subscribe if you'd like to get access to all current and future features and add-ons. But if you don't need the new paid features, you can continue using MysterSmith instead of the PeekSmith app totally FREE.

---

**- How can I install MysterSmith? I don't see it in the AppStore or Google Play...**

- MysterSmith is an underground app, not available for the general public. You can install it from TestFlight on iOS, and install an APK version on Android. For the detailed download information [**please click here**](https://mystersmith.info/site/about-mystersmith/download-the-app/).

---

**- Can I use MysterSmith the same way I used the PeekSmith app, without subscribing or paying more?**

- Yes! MysterSmith basically started as a PeekSmith app "clone", and you can continue using every feature, every purchased add-on the same way. Some features (like advanced Atom 2 functions) that were added to the PeekSmith app after March 2025, might be only available in the PeekSmith app. In MysterSmith you will also get some new features for free. However, some new routines and premium features that will be added later, will require either a subscription or a one-time purchase.

---

**- Can I continue using the PeekSmith app? Will it be updated regularly?**

- Sure! The PeekSmith app won't be abandoned, there will be updates, and support for new Electricks hardware will be added. In fact you will still need the PeekSmith app for firmware updates, even if you "switch" to MysterSmith. Also some exclusive features (like advanced Atom 2 functions) will be only added to the PeekSmith app, which is now maintained by Electricks. You can go ahead and use both apps at the same time.

---

**- Can I use MysterSmith on both Android and iOS?**

- Yes! Like all my apps, MysterSmith will be available for both platforms. On Android I will distribute the app as an APK installer, and on iOS you will be able to get it on TestFlight (later I will publish it to the AppStore as an Unlisted app, so no outsiders will find it).

---

**- If I switch to MysterSmith, and would like to use the new features/routines, will I have to subscribe?**

- No, there will be one-time purchase options for every new feature and routine. Subscriptions will give you a lot more benefits though (please read the corresponding pages as well).

---

**- If I subscribe, will I access all functions/routines in the app, or there could be some additional fees?**

- All subscribers will have access to all functions/features and routines in the app. However, there could be some special routines - like A.I. video avatar predictions - which would require a usage-based credit system (using 3rd party paid services through my service). PREMIUM subscribers will get some free credits, and a 50% discount of all credit packages. As a bonus, Google text recognition credits will be FREE for all subscribers!

---

**- How can I subscribe to MysterSmith?**

- Please **[sign in to the Account Manager](https://bsmagic.app/account/)** with the same account as you use on your phone to sign in to the MysterSmith app.
